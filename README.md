# Print Shop System (Štamparija)
A MEAN-stack / Angular web app for a print shop, built as a university project for the web development course at ETF Belgrade.
Customers order print products, printers manage their catalog and orders, and admins run categories, stats and public tenders.

- **Frontend:** Angular 20 (standalone components)
- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB (Mongoose) ('stamparija' running on `localhost:27017`)
- **Additionally:** bcrypt (auth), Multer (image uploads), PDFKit (invoice/tender PDFs), Nodemailer (email)
